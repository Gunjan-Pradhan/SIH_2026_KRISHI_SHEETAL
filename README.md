# Krishi-Sheetal

## Smart Modular Cold-Chain Infrastructure for Fresh Produce

Krishi-Sheetal is a smart modular cold-chain system designed to reduce post-harvest losses by combining centralized cold storage with intelligent transport crates.

The system uses grid-powered refrigeration for centralized pre-cooling, while solar energy is used to charge the batteries of transport crates. Each reusable insulated crate integrates temperature and humidity sensing, battery monitoring, communication, and a low-power Peltier-based thermal-maintenance system to preserve produce during transportation.

## Key Features

- Centralized grid-powered cold storage for efficient pre-cooling and storage
- Reusable intelligent transport crates with PU/PIR insulation
- Real-time temperature and humidity monitoring
- Battery SOC and estimated remaining-runtime monitoring
- Peltier-based temperature maintenance during transportation
- Solar-powered battery charging for transport crates
- Unique crate ID for tracking and traceability
- Real-time alerts for temperature, humidity, battery, and system failures
- Live shipment and crate tracking
- Separate dashboards for infrastructure management and farmers
- Delivery confirmation and produce-condition monitoring
- Market and selling information for farmer decision support
